# Contributing

Thanks for your interest in TaskFlow.

## Local development

Follow the setup instructions in the README. Keep your local `.env` file private and never commit secrets, database dumps or personal information.

## Pull requests

- Keep changes focused and explain the user workflow affected.
- Add or update tests for validation, API behaviour and security-sensitive changes.
- Run `npm test` and `npm run build` before opening a pull request.
- Preserve workspace-level data isolation.
- Document new environment variables and database migrations.
